# Changelog

## 0.2.0 — 2026-08-14

- **DeepSeek verifier backend.** `deepseek-v4-flash` is now the default
  verifier when `DEEPSEEK_API_KEY` is set. Reasoning effort and output budget
  are configurable via `DEEPSEEK_EFFORT` (`off` / `low` / `high` / `max`,
  default `high`) and `DEEPSEEK_MAX_TOKENS` (default 32768).
- **Prefix-cache optimization.** Prompts keep the criterion at the tail and
  scoring warms one request per distinct prompt prefix before fanning out,
  raising the backend prefix-cache hit rate from 5.2% to 78.4% on
  Terminal-Bench 2.1 (~3.4× cheaper input).
- **Token accounting.** Every verifier call records input / cached-input /
  output / reasoning tokens in the process-wide `llm_verifier.USAGE` counter;
  `token_usage()` and `format_usage()` report per-run usage.
- **Self-verification benchmark.** New `terminal_bench_2.1` benchmark:
  mini-swe-agent trajectories generated by `deepseek-v4-flash` and verified
  by the same model. `scripts/run_bo3.py` and `scripts/run_bo5.py` reproduce
  the best-of-3 and best-of-5 results standalone, each with its own score
  cache, and `scripts/run.py --n-trials N` truncates any benchmark to
  best-of-N.

## 0.1.0

- Initial release: fine-grained logprob reward, Probabilistic Pivot
  Tournament best-of-N selection (`select` / `compare`), progress tracking
  (`track` / `ProgressTracker`), multimodal inputs, benchmark runners for
  Terminal-Bench, SWE-Bench Verified, and MedAgentBench.
